# Daily Job Scout routine

Run from the auto-job repository:

```sh
./bin/auto-job scout run
```

Read the generated `reports/daily/YYYY-MM-DD.md`. Report only newly recorded high-priority or strong-fit opportunities, deadlines, and actionable scanner failures. A completed run with no new postings is a normal “no matches” outcome; a non-zero scan or all-source failure is an infrastructure failure. Never apply, contact a company, change profile facts, or fabricate a job detail.
