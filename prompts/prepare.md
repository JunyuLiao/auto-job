# Application preparation

1. Read the JD and produce a requirement-to-verified-evidence table.
2. Tailor only by reordering, selecting, and clarifying facts already in `profile/evidence.yml` and `CV.pdf`.
3. Run an independent reviewer using `prompts/reviewer.md`; criticism comes before revision.
4. Compile the one-page resume using the existing template when available.
5. Run `./bin/auto-job verify output/<resume>.pdf` and preserve the report.
6. Prepare factual answers with `./bin/auto-job answer '<question>'`; stop on manual-review questions.
7. Human review and manual submission are mandatory. Never auto-submit LinkedIn.
