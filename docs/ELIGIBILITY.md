# Eligibility

Eligibility is evaluated separately from technical fit. Values are `PASS`, `SOFT_NOTE`, `UNCERTAIN`, or `FAIL`. Work authorization is read from the local profile; citizenship-only language is never silently treated as equivalent to another status. Explicit graduation ranges are hard checks against the verified undergraduate graduation in the local profile. Return-to-school wording is a `SOFT_NOTE`, never an automatic rejection. An unconfirmed graduate-school plan never satisfies a requirement.
